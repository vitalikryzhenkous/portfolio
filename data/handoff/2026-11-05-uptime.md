## What is new since the case's snapshot (2026-11-04)

1. **A native macOS menu-bar app** (repo uptime-apple, SwiftUI, sandboxed, macOS 14+).
   - A panel with one card per Claude Code session: state, what it waits for, context ring, CI/PR dots.
   - Buddy (the board's cat) in the menu bar; his eyes show the state: green working, yellow waiting, red a dialog.
   - Global hotkey ⌥⌘U opens the card that needs you most.
   - Reply to a waiting agent and `/compact` from the card (only sessions in tmux).
   - Texts and sprites come from the board: one translation covers board and app.
   - GitHub, 2026-11-05 evening: 26 merged PRs, 2026-11-03 → 2026-11-05.
2. **Answering Claude Code permission dialogs from the app** (opt-in on the board, off by default).
   - A Claude Code hook sends the request to the board; the first answer wins (app or terminal).
   - Deny is everywhere: card, notification. Allow once only in a popover that shows the whole command.
   - Dangerous or partial commands, and paths outside the project: deny only.
   - The command text never goes into the log.
   - A macOS notification for each request, with Deny and Open; withdrawn when the request closes anywhere.
   - Seen live on 2026-11-05: Deny from the notification reached the board, logged `by: app`; the command did not run.
3. **Onboarding: pair a device with a one-time code** (board and Mac app merged 2026-11-05).
   - The board prints a 6-digit code (2 minutes, one use) and an `uptime://pair` link.
   - The app exchanges it for its own token. The main API token never leaves the server.
   - The server keeps only a SHA-256 of each device token. Any device can be revoked at once.
   - Claims are limited to 5 a minute.
   - First-run wizard: address → code (⌘-click the link in Terminal) → connection check → notifications.
     It opens by itself while the app has no token; the Copy button gives the exact `ssh user@board-host '…'`.
   - Seen live on 2026-11-05: a real Mac paired through the wizard — the board logged `pair/claim` 200 and
     listed the device (`tools/pair.py --list`).
   - Found live and fixed the same day: the first Copy command used a host name the Mac could not resolve.

## Engineering facts worth a line

- CI on every PR (macOS 15): Swift tests with strict concurrency as errors plus Thread Sanitizer, and an unsigned
  app build. 105 UptimeKit tests on the pairing PR.
- Board side: Python unittest; 59 tests after the pairing PR, plus an end-to-end run on a throwaway board.
- The app's testable logic lives in a Swift package (UptimeKit); the app target is thin.
- Owner's design decisions: allow only beside the whole command; notification buttons Deny + Open (no Allow);
  pairing by one-time code instead of copying a token.
